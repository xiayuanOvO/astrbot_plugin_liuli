# 琉璃

面向插件开发与调试的 AstrBot 角色养成插件，包含角色状态、货币与签到、宠物养成和冒险者公会基础委托。首次使用任意琉璃命令时会自动创建角色档案。

## 命令

| 命令 | 用途 |
| --- | --- |
| `/查询` | 查看自己的玩家档案 |
| `/改名 <昵称>` | 修改角色昵称 |
| `/公会` | 查看公会入口和冒险者等级 |
| `/注册冒险者` | 注册冒险者身份 |
| `/查看委托 [编号]` | 列出委托或查看委托详情 |
| `/接取委托 <编号>` | 接取委托 |
| `/余额` | 查看货币余额 |
| `/签到` | 领取当天签到奖励（按周一至周日分别配置） |
| `/消费 <数量>` | 消耗自己的货币 |
| `/领养宠物 [宠物名称]` | 选择一只免费初始宠物；不填名称时显示目录 |
| `/我的宠物 [宠物序号]` | 列出或查看自己的宠物 |
| `/宠物改名 <宠物序号> <昵称>` | 修改宠物昵称 |
| `/出战宠物 <宠物序号>` | 设置当前宠物 |
| `/宠物技能 [宠物序号]` | 查看宠物技能，省略序号时查看当前宠物 |
| `/宠物技能装备 <宠物序号> <技能名称>` | 装备已学技能 |
| `/宠物技能卸下 <宠物序号> <技能名称>` | 卸下技能但保留学习记录 |
| `/精灵对战 @玩家` | 在群聊向另一位玩家发起对战挑战 |
| `/接受对战`、`/拒绝对战` | 处理收到的挑战 |
| `/对战状态` | 查看待处理挑战或当前回合 |
| `/精灵技能 <序号或技能名称>` | 在自己的回合施放已装备的对战技能；输入“普通攻击”可直接攻击 |
| `/精灵防御`、`/精灵认输` | 防御或结束当前对战 |
| `/世界地图` | 查看唯一世界的国家、城市、副本和解锁状态 |
| `/国家 <国家名称或简称>`、`/城市 <城市名称>`、`/副本 <副本名称>` | 浏览地点与副本难度；国家支持拼音首字母简称 |
| `/进入副本 <副本名称> <难度名称>` | 使用当前出战宠物开始单人探索 |
| `/探索副本`、`/副本选择 <选项序号>` | 前进触发事件并处理分支选择 |
| `/副本状态`、`/退出副本` | 查看并续玩探索，或主动撤退 |
| `/宠物休息` | 在当前城市恢复出战宠物的生命和魔力 |

副本遭遇战沿用 `/精灵技能` 和 `/精灵防御`；野生精灵由服务端自动行动，击败敌人后立即获得宠物经验。路线、事件选择、战斗和进度均持久化，重启后可通过 `/副本状态` 继续。

命令应在 AstrBot 已连接的平台会话中使用。插件以平台名称和发送者 ID 作为角色键，避免不同平台的相同 ID 共用档案。
首次使用任意琉璃命令时会用平台昵称初始化角色；之后的平台昵称变化不会覆盖角色名，需通过 `/改名 <昵称>` 修改。

## 数据与开发

运行数据保存在 AstrBot 插件数据目录 `data/plugin_data/astrbot_plugin_liuli/liuli.sqlite3`。角色按平台名称和发送者 ID 隔离保存。

插件使用 AstrBot 注入的事件对象与生命周期，命令通过 `yield event.plain_result(...)` 返回消息。货币名称和每周签到奖励由 AstrBot 插件配置管理，不使用额外配置加载器。

项目分层、数据流和扩展约定见 [项目架构与目录结构.txt](项目架构与目录结构.txt)。
货币名称配置、余额、签到奖励和消费的方案见 [货币系统设计](docs/currency-system-design.md)。
货币名称及周一至周日签到奖励可在 AstrBot 插件配置中分别修改；默认奖励为 10、12、14、16、18、20、30 银币。
宠物属性、等级成长、技能和持久化方案见 [宠物系统设计](docs/pet-system-design.md)。
玩家间精灵对战的挑战、回合、结算与持久化方案见 [精灵对战设计](docs/spirit-pvp-design.md)。
世界国家、城市、副本难度、路线事件与野生精灵刷级方案见 [世界地图与副本系统设计](docs/dungeon-system-design.md)。
